# Troubleshooting

## The app won't start

1. Make sure you're running the latest version.
2. Check that Node.js is installed (`node -v`).
3. Re-run the installer.

## I get a "permission denied" error

Run the terminal as administrator, or prefix the command with `sudo` on macOS/Linux.

## Still stuck?

Open a support ticket and include the error message and your OS version.
